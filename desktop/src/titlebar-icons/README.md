# Title bar icons

Icons for the desktop title bar (the base renderer in `index.html`). These are
UI icons, not the app icon -- that lives in `assets/` and is generated by
`pnpm run build-icons`.

| File                | Used for                                  |
| ------------------- | ----------------------------------------- |
| `health.svg`        | Health tab (heart with an EKG trace)      |
| `settings.svg`      | Settings tab (gear)                       |
| `downloads.svg`     | Downloads tab (down arrow over a line)    |
| `new-dashboard.svg` | "+ Dashboard" button (plus in a rhombus)  |

Conventions, so the set stays consistent:

- 24x24 `viewBox`, outline style: `fill="none"`, `stroke-width="1.75"`, round
  caps and joins.
- `stroke="currentColor"`, so the icon takes the CSS `color` of its button
  (hover, active, and disabled states then need no extra SVG work). This only
  works when the SVG is inlined into the DOM, e.g. imported with Vite's
  `?raw` suffix and set as `innerHTML` -- not when used via `<img src>`.
- The gear's tooth coordinates were generated (8 teeth, outer radius 10, root
  radius 7.6); regenerate them rather than hand-editing individual points.
